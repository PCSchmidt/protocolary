# TransCelerate DDF Project Notes

## 1. Project Overview
- **Project Goals**: Systematically explore TransCelerate DDF repositories to adapt them for commercial use
- **Timeline**: Part-time project spanning multiple weeks
- **Repositories**:
  - ddf-home: Documentation and website content
  - ddf-sdr-api: .NET 6 Web API for study definitions
  - ddf-sdr-ui: Angular-based user interface
  - ddf-sdr-platform: Terraform IaC for Azure deployment
  - ddf-directory: Directory of DDF-compatible solutions
  - ddf-sdr-support: Support repository
