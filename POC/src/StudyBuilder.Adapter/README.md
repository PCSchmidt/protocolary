# Study Builder Adapter

This component integrates with upstream study design systems to retrieve study design data and transform it to the USDM format for storage in the SDR.

## Features

- Integration with study design systems
- Transformation to USDM format
- Validation against USDM schema
- Submission to SDR Core API

## Technology Stack

- .NET 6 or Node.js
- HTTP client for API communication
- JSON schema validation

## Getting Started

1. Ensure .NET 6 SDK or Node.js is installed
2. Configure connection to study design system in appsettings.json
3. Configure connection to SDR Core API in appsettings.json
4. Run the application using dotnet run or 
pm start
